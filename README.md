# Full-Stack Todo List

Task management web application with an HTML, CSS, and JavaScript frontend, an Express API, and MySQL persistence.

**Category:** Full-Stack Web App

**Stack:** JavaScript, HTML, CSS, Node.js, Express, MySQL, Docker

**Status:** Portfolio-ready educational project

## Run Locally

```bash
npm start
```
