# Full-Stack Todo List

## Vue d'ensemble

Application web de gestion de tâches avec frontend HTML, CSS et JavaScript, API Express et persistance MySQL.

## Objectif

Ce projet de portfolio technique documente le flux implémenté et ses limites actuelles sans modifier le comportement de l'application.

## Stack

JavaScript, HTML, CSS, Node.js, Express, MySQL, Docker
